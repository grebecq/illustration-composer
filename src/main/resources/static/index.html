Подключение ИИ

ИИ подбирает объекты по смыслу. Подойдёт любая модель: локальная (Ollama, LM Studio) или по ключу (OpenRouter, OpenAI, Anthropic). Ключ хранится только в памяти сервера до перезапуска и в браузер не возвращается.
